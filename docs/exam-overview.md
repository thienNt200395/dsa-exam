# Exam Overview: Data Structures and Algorithms

## Purpose
This exam checks whether a student can describe and implement three fundamental
algorithms: one searching algorithm, one sorting algorithm and one recursive algorithm.

## Format
- 3 questions, each worth equal weight unless the instructor states otherwise.
- Every question has two parts:
  1. Write the steps of the algorithm in **pseudocode**.
  2. **Implement** the algorithm in a programming language of the student's choice.
- Reference solutions in this repository are written in Java.

## Topics covered
| # | Topic | Category | Key skills assessed |
|---|-------|----------|---------------------|
| 1 | Linear search | Searching | Iteration, comparison, return value for "not found" |
| 2 | Bubble sort | Sorting | Nested loops, swapping, loop bounds |
| 3 | Factorial | Recursion | Base case, recursive step, termination |

## Learning outcomes
After the exam, a student who passes can:
- Express an algorithm as clear, language-independent pseudocode.
- Translate pseudocode into working code.
- Reason about the time complexity of simple algorithms.
- Identify the base case and recursive step of a recursive definition.

## Allowed language
Any language. Pseudocode has no fixed syntax: it only has to be clear, complete and in the
correct order.
