Question 1: Implement the linear search algorithm

Write the steps in pseudocode

Step 1: Start at the leftmost element and compare each element with x
Step 2: If an element equals x, return its index
Step 3: If the end is reached without a match, return -1

FUNCTION linearSearch(values, x)
    FOR i FROM 0 TO length(values) - 1 DO
        IF values[i] = x THEN
            RETURN i
    RETURN -1

Question 2: Implement the bubble sort algorithm

Write the steps in pseudocode

Step 1: Compare each pair of adjacent elements, starting from the first position
Step 2: If the right element is smaller than the left one, swap them
Step 3: After one pass the largest element has "sunk" to the end of the array
Step 4: Repeat on the remaining part until the array is sorted in non-decreasing order

FUNCTION bubbleSort(values, n)
    FOR pass FROM 0 TO n - 2 DO
        FOR i FROM 0 TO n - 2 - pass DO
            IF values[i] > values[i + 1] THEN
                swap values[i] and values[i + 1]

Question 3: Implement a recursive algorithm that computes the factorial

Write the steps in pseudocode

Recursive definition:
    0! = 1                        (base case)
    n! = n × (n - 1)!  for n > 0  (recursive step)

FUNCTION factorial(n)
    IF n = 0 THEN
        RETURN 1
    RETURN n × factorial(n - 1)

Example: 3! = 3 × 2! = 3 × 2 × 1! = 3 × 2 × 1 × 0! = 6
